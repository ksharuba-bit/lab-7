# Лабораторна робота №7 — користувацькі класи, успадкування та об'єкти

**Студент:** Шоробура Костянтин  
**Група:** ІК-52

## Тема проєкту
Розроблення інформаційної системи для статистичного аналізу футбольних турнірів із використанням технології об'єктно-орієнтованого програмування.

## Обраний варіант
**Варіант 2** — базовий клас `Function` і похідні класи `LinearFunction`, `QuadraticFunction`, `CubicFunction`.

Такий варіант зручно пов'язати з проєктом статистичного аналізу: різні типи функцій можуть використовуватися як математичні моделі для аналізу трендів та показників.

## Реалізовано
- базовий абстрактний клас `Function`;
- публічне успадкування;
- похідні класи лінійної, квадратичної та кубічної функцій;
- конструктори без параметрів та з параметрами;
- захищення даних через `private`;
- робота з довільною кількістю записів через `vector<unique_ptr<Function>>`;
- виведення інформації про об'єкти;
- пошук за типом функції;
- редагування записів;
- обчислення значення функції для заданого `x`.
